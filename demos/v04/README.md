# Story Animator v0.4 — 15s Eco audio-sync QA

Nine timed camera cuts from eight real Pollinations images. Five new Quest-only I2I generations, using the first frame as reference. The four already produced French TTS/STT utterances, native 720x1280 subtitles, and locally rendered soundtrack are reused. Three cuts in each of the three 5-second windows. Images follow measured speaker boundaries. See execution-report.json for actual requested model IDs, per-call logs, timings and limitations. No Paid models were invoked for these new images. Observed balance delta for five new calls 0.025 Pollen, not independently verified as per-call costs.
