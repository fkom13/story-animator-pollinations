# Story Animator — Audio-first QA pilot (15 seconds)

Experimental audiovisual proof-of-concept, 2026-11-09.

Three Pollinations Quest-only images (first T2I, following I2I), four speaker-separated utterances with Microsoft MAI Voice Flash, transcribed with MAI Transcribe 2, 15s H264 AAC MP4 in 720x1280 with burned-in measured subtitles. Original synthetic procedural music and SFX made for this pilot, not sourced from Free Video Maker/Pruna or external copyrighted works. One FFmpeg mix used music ducking during speech.

**Not the official public Code Agent release. Not artistically approved; use for playback/QA only.** Costs per call are not verified and are intentionally not claimed. The CC0 public-asset selection workflow is separately tested; this test score is original.
